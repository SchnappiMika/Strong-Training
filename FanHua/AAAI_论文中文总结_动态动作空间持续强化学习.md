# Calibrated Lifelong Reinforcement Learning for Efficient Adaptation to Changing Action Sets

## 中文整理：动态动作集合下的校准持续强化学习

> **论文英文题目**：Calibrated Lifelong Reinforcement Learning for Efficient Adaptation to Changing Action Sets  
> **文件来源**：`AAAI_英文档_蒋奇奇_final_version_no_appendix.pdf`  
> **文献类型**：AAAI 风格匿名投稿稿；论文首页标注为 `Anonymous submission`，文件中未给出正式作者信息。  
> **核心方法**：Cal-LAICA（校准版 LAICA）  
> **研究主题**：当环境中的可用动作集合不断增加时，如何让强化学习智能体复用旧知识、快速适应新动作，并避免适应初期性能崩溃。

---

## 1. 一句话概括

这篇论文研究的不是通常意义上的“换一个地图或改变奖励参数后的泛化”，而是更具体、更困难的**动作集合持续扩展**问题：智能体已经学会一部分动作，训练过程中又不断出现新的离散动作。论文发现，已有持续强化学习方法在新动作加入后会出现明显的“先遗忘、后恢复”现象，根本原因主要是动作表示空间中的 **Q 值被低估**。作者借鉴离线到在线强化学习的价值校准思想，提出 Cal-LAICA：

1. 在隐式动作表示空间中对 Q 值进行保守校准，防止新动作加入后价值估计过低；
2. 使用 Offline-Online Replay Buffer（OORB）同时保留旧阶段和当前阶段经验，提高样本利用率；
3. 只在训练初期使用一次高质量离线数据，之后继续在线适应新动作，因此兼具离线预训练的稳定性和持续学习的灵活性。

在 MiniGrid 的四类迷宫任务上，Cal-LAICA 在动作集合连续扩展时表现出更高的归一化回报、更快的恢复速度和更好的数据效率；代价是当前方法主要针对**离散动作空间**，对连续动作空间尚未解决。

## 2. 研究背景与问题动机

### 2.1 固定动作空间是传统 RL 的隐含前提

标准马尔可夫决策过程（MDP）写作：

\[
M=(\mathcal S,\mathcal A,P,R,\gamma),
\]

其中状态空间为 \(\mathcal S\)，动作空间为 \(\mathcal A\)，转移函数为 \(P\)，奖励函数为 \(R\)，折扣因子为 \(\gamma\)。大多数强化学习算法默认 \(\mathcal A\) 在训练全程固定。但真实任务可能持续出现新的可选动作，例如：

- 机器人逐步获得新的执行器或控制方式；
- 推荐系统不断加入新的内容或操作选项；
- 游戏环境在运行过程中解锁新的技能、按钮或行为；
- 大规模离散动作空间按阶段逐步开放。

如果动作集合变化，原策略网络、Q 网络和经验数据就不再与当前环境完全匹配。简单地从头训练浪费旧知识；直接沿用旧策略又可能把旧动作的偏好错误地迁移到新动作上。

### 2.2 Lifelong RL 的基本思路

论文采用持续/终身强化学习（lifelong RL）的视角。令第 \(k\) 个阶段的环境为 \(M_k\)，随着动作集合变化，环境从 \(M_{k-1}\) 转换为 \(M_k\)。智能体需要在多次变化中持续学习，而不是每次变化后重新初始化。

现有方法通常将策略拆成两部分：

- **动作表示策略** \(\beta(e\mid s)\)：根据状态 \(s\) 在连续的潜在动作表示空间 \(\mathcal E\) 中选择表示 \(e\)；
- **动作映射函数** \(\phi(e)\)：把潜在表示映射为当前环境中的真实离散动作 \(a\)。

其关系可写作：

\[
e_t\sim\beta(\cdot\mid s_t),\qquad a_t=\phi(e_t).
\]

这样做的好处是：动作表示空间可以在不同阶段复用，动作集合变化主要由映射函数 \(\phi\) 适配，而不必把策略完全重写。

### 2.3 现有方法的关键失败现象

论文重点分析 LAICA（Learning Actions as an Interpretable Continuous Abstraction）在动作集合变化后的表现。LAICA 能学习动作的潜在表示，也能继续适应新增动作，但在每次动作集合变化后通常出现：

1. 平均回报突然下降；
2. 策略在一段时间内像是“忘掉”以前已经掌握的行为；
3. 需要大量交互样本才能恢复原来的性能；
4. 动作集合变化次数越多，价值估计越不稳定，后续恢复越困难。

论文将这种现象称为适应阶段的 **catastrophic performance degradation**，并把研究问题聚焦为：

> 为什么动作集合变化会让原本有效的持续学习策略在早期突然失效？能否在不重新参数化整个策略的前提下，快速、稳定地适应新增动作？

## 3. 论文的主要贡献

论文明确列出三项贡献：

1. **分析性能退化原因**：指出现有持续强化学习在新动作加入后性能下降，核心原因是表示动作空间中的价值函数被低估。这是论文声称首次针对该问题进行系统处理。
2. **提出价值校准方法**：把离线到在线 RL 中的价值校准思想迁移到动作表示空间，构造 Cal-LAICA，限制 Q 值在适应初期过度偏低。
3. **给出遗憾界并提升样本效率**：理论上推导 Cal-LAICA 的累计遗憾界，同时设计 OORB 回放机制保存不同阶段经验，减少重新收集数据的成本。

## 4. 数学建模与动作表示

### 4.1 策略与价值函数

固定策略 \(\pi_k\) 在第 \(k\) 个环境中的状态价值函数为：

\[
v_{\pi_k}(s)=\mathbb E\left[\sum_{t=0}^{\infty}\gamma^tR_t\mid s,\pi_k\right].
\]

动作表示策略 \(\beta_{\pi_\theta}\) 先选潜在动作表示，再由映射函数选真实动作。论文用如下关系表达真实动作策略：

\[
\pi_\theta(a\mid s)=\int_{\phi_{\pi_\theta}^{-1}(a)}\beta_{\pi_\theta}(e\mid s)\,de.
\]

在动作表示空间中，动作价值可写为：

\[
Q^{\pi_\theta}(s,a)=Q^{\beta_{\pi_\theta}}(s,e).
\]

对应的状态价值函数是对所有真实动作对应的潜在区域进行积分：

\[
v^{\pi_\theta}(s)=
\sum_{a\in\mathcal A}
\int_{\phi^{-1}_{\pi_\theta}(a)}
\beta_{\pi_\theta}(e\mid s)Q^{\pi_\theta}(s,a)\,de.
\]

这一步很关键：策略优化发生在潜在动作空间，但真实环境仍执行离散动作。动作集合变化会改变“潜在区域到真实动作”的映射，从而影响原来 Q 值的含义。

### 4.2 动作集合变化造成的映射错位

论文用一维潜在动作空间示意这一问题。原来某段表示区域可能全部映射到动作 \(a_1\)。新增动作 \(a_2\) 后，该区域被重新划分，一部分仍映射到 \(a_1\)，另一部分改为映射到 \(a_2\)。

因此，旧阶段学到的 \(Q(s,a_1)\) 不能简单视作新阶段每个潜在位置的可靠 Q 值。适应初期数据又很少，导致新阶段价值函数在关键区域可能严重低估。策略梯度会把低估区域的概率压低，使智能体减少探索这些区域；这样又更难采到纠正低估所需的数据，形成恶性循环。

## 5. 性能退化的原因分析

### 5.1 LAICA 的两个适应阶段

动作集合变化后，LAICA 大致经历两个阶段：

**阶段 1：离线收集反馈并更新动作映射**

- 收集环境对动作的反馈；
- 学习新的动作表示映射 \(\hat\phi_{k+1}\)；
- 学习或更新逆动力学函数 \(\psi_{k+1}\)；
- 这一阶段主要利用旧阶段的知识，并不立即在线优化表示策略。

**阶段 2：在线优化动作表示策略**

- 固定或继续使用已更新的 \(\hat\phi_{k+1}\) 与 \(\psi_{k+1}\)；
- 与新环境交互；
- 更新潜在动作表示策略 \(\beta_{k+1}\) 和价值函数。

### 5.2 为什么会“先遗忘”

阶段 1 更新了动作映射，但旧的表示策略和价值函数仍然保留。某些潜在动作表示不再对应过去的真实动作，然而其旧 Q 值仍被当作初始化或训练信号使用。

在阶段 2 的早期：

- 若某动作 Q 值被高估，策略可能过度选择它，随着新样本到来逐渐修正；
- 若某动作 Q 值被低估，策略会降低其选择概率，反而很少再收集该动作的纠正样本；
- 低估通常比高估更难通过在线策略改进自动恢复，因为策略本身已经停止访问低估区域。

论文在 Four Rooms 实验中观察到：平均 Q 值在动作集合切换后先下降，平均回报下降的时间段与平均 Q 值下降基本重合。第一次切换后 LAICA 还能恢复，第二、第三次切换后则可能无法收敛，说明错误价值估计会累积。

## 6. Cal-LAICA 方法

Cal-LAICA 由两个核心部分构成：**价值函数校准**和**在线-离线混合回放**。此外，训练开始阶段增加一次离线预训练。

### 6.1 价值校准的来源：Cal-QL 思想

离线到在线 RL 中也存在价值低估或分布偏移问题。Cal-QL 的思想是让当前策略的 Q 值不低于参考策略的价值估计。论文先给出抽象约束：

\[
\mathbb E_{a\sim\pi_\theta}[Q^{\pi_\theta}(s,a)]
\geq
\mathbb E_{a\sim\mu}[Q^{\mu}(s,a)],
\]

其中 \(\mu\) 是参考策略。直观上，更新后的策略不应该因为估计误差而被评价得比已有可靠策略更差。

### 6.2 在动作表示空间中的校准正则项

论文把离散动作版本改写到潜在表示空间。表示空间的价值函数满足：

\[
v^{\pi}(s)=
\sum_{a\in\mathcal A}
\int_{\phi^{-1}_{\pi}(a)}
\beta_\pi(e\mid s)Q^{\beta_\pi}(s,e)\,de
\equiv v^{\beta_\pi}(s).
\]

由此得到动作表示空间中的校准正则项：

\[
R(\theta)=
\mathbb E_{s\sim D}
\left[\max\left(Q^{\beta_{\pi_\theta}}(s,e),V^\mu(s)\right)\right]
-
\mathbb E_{s,a\sim D}
\left[Q^{\beta_{\pi_\theta}}(s,e)\right].
\]

实现时，该项加入价值学习目标，使估计 Q 值不能随意低于参考策略的价值。论文强调它不是简单把所有 Q 值强行抬高，而是通过参考价值提供一个下界，重点处理新动作刚出现时的低估问题。

### 6.3 Offline-Online Replay Buffer（OORB）

传统持续学习方法在动作集合变化时往往清空旧回放池，只使用当前 MDP 的新样本。论文认为这会造成两个问题：

- 旧阶段已经收集的经验被浪费；
- 当前阶段样本少且分布窄，价值估计容易不稳定。

OORB 将经验分成两个池：

- **offline buffer**：保存前一阶段或更早阶段积累的转移；
- **online buffer**：保存当前动作集合和当前策略下新收集的转移。

采样时使用伯努利混合策略：以概率 \(p\) 从 offline buffer 采样，以概率 \(1-p\) 从 online buffer 采样。\(p\) 是训练超参数。

当动作集合再次变化时：

1. 把当前 online buffer 合并进 offline buffer；
2. 清空 online buffer；
3. 在新动作集合下重新收集当前数据；
4. 继续用新旧数据混合训练。

这相当于在持续学习中保留一个长期记忆，同时保留对当前分布的适应能力。

### 6.4 初始离线预训练

论文在第一次动作集合变化之前使用专家模型产生的高质量数据，对动作表示策略进行约 5,000 个 episode 的离线预训练。之后进入普通在线学习。其设计目标是避免训练从随机、低质量策略起步，同时不要求每次新动作出现都重新准备专家数据。

### 6.5 Cal-LAICA 的流程

根据论文表 1，算法流程可整理为：

```text
输入：动作表示策略 β、动作映射函数 ϕ、逆动力学函数 ψ
初始化 β、ϕ、ψ
使用 CQL 对模型进行一次离线预训练

for 每次动作集合变化：
    更新当前可用动作集合
    若 online buffer 非空：
        将 online buffer 合并到 offline buffer
        清空 online buffer
    使用当前环境探索，并把数据放入 online buffer
    重复若干次：
        从 online buffer 采样
        更新 ϕ 和 ψ
    在动作集合保持不变期间：
        以概率 p 从 offline buffer 取 batch
        否则从 online buffer 取 batch
        根据状态由 β 产生潜在动作表示 e
        通过 ϕ 将 e 映射为真实动作 a
        更新 β
        使用 TD 误差更新 critic，并加入价值校准正则项
```

方法继承了 LAICA 的特点：新动作到来时不必完全重建策略；同时加入离线到在线方法的两个机制：初始离线预训练和保守价值校准。

## 7. 理论分析：遗憾界

### 7.1 遗憾的定义

论文将第 \(k\) 个动作集合阶段的交互轮数记为 \(N_k\)，总变化次数为 \(K\)。累计遗憾衡量最优策略价值与实际策略价值之差：

\[
\mathrm{Reg}(K)=
\mathbb E_{s\sim D_0}
\left[
\sum_{k=1}^{K}\sum_{n=1}^{N_k}
\left(V^{\pi^\star}(s)-V^{\pi_{k,n}}(s)\right)
\right].
\]

论文还定义了潜在动作表示空间中的遗憾，用 \(V^{\beta\pi^\star}\) 与 \(V^{\beta\pi_{k,n}}\) 表示。

### 7.2 Theorem 1 的界

论文给出的 Cal-LAICA 遗憾界为：

\[
\widetilde O\left(
\min\left\{
C^{\beta\mu}_{\beta\pi^\star}H\sqrt{dN\log|\mathcal F|},
NE_{\rho}\left[
V^{\beta\pi^\star}(s_0)-V^{\beta\mu}(s_0)
+H\sqrt{d_{\beta\mu}N\log|\mathcal F|}
\right]
\right\}\right).
\]

其中：

- \(N=\sum_{k=1}^{K}N_k\)：整个生命周期的交互步数；
- \(H\)：有限时域长度；
- \(\mathcal F\)：Q 函数的函数类；
- \(d\)：Bellman 双线性秩；
- \(C^{\beta\mu}_{\beta\pi^\star}\)：校准 Bellman 误差转移系数；
- \(V^{\beta\pi^\star}(s_0)-V^{\beta\mu}(s_0)\)：最优策略与参考策略在初始状态的价值差。

公式的直观含义是：第一项包含随样本量增长的平方根项；第二项还包含参考策略价值差等因素。不能据此断言任何参考策略、任何环境下整个表达式都必然次线性，必须保留定理的假设与各项系数的条件。校准机制的理论作用不是保证每个时间点最优，而是控制价值估计误差向后续策略更新传播的程度；也不能将这一界直接套用到本文之外的跨游戏任务。

论文附录进一步定义了普通 Bellman Error Transfer Coefficient、Calibrated Bellman Error Transfer Coefficient，以及表示动作空间版本的系数 \(C_{\beta\pi}\) 和 \(C^{ref}_{\beta\pi}\)，并将动作表示策略的 Q 函数写入 Bellman 分析。附录中的 Theorem 2 是把离线到在线 RL 与 LAICA 理论结合后的表示空间遗憾界。

## 8. 实验设置

### 8.1 环境与任务

论文使用 MiniGrid 风格的四类迷宫任务：

1. Four Rooms；
2. Crossing；
3. Dist Shift Maze；
4. Empty Maze。

正文实验部分重点描述前三类迷宫，图 5 和消融图 7 同时展示 Empty Maze，因此总实验任务数为四个。

每个任务中：

- 智能体控制一个具有 8 个方向/执行器的机器人；
- 完整动作空间共有 \(2^8=256\) 个离散动作，对应 8 个二元执行器的组合；
- 训练开始时只开放部分动作；
- 将 256 个动作随机分成 5 组并逐阶段开放；
- 前四组各 51 个动作、最后一组 52 个动作，\(4\times51+52=256\)。原总结把上标 \(2^8\) 误读成了 28，此处已更正；
- 每次动作集合更新时，还加入新的目标点，强化环境的持续变化特征；
- 目标是到达最终绿色目标，达到最大步数则终止；
- 中间设置一系列子目标，降低稀疏奖励带来的探索难度。

### 8.2 状态、动作与奖励

**状态**：

- 智能体位置；
- 当前目标位置；
- 共 4 维实数向量；
- 各维坐标线性归一化到 \([0,1]\)。

**动作**：

- 完整集合 \(2^8=256\) 个离散动作；
- 可用动作按五个阶段逐渐加入。

**奖励**：

- 到达一个目标点时只给一次正奖励；
- 奖励为 `100 / 到达该目标所使用的步数`；
- 因此更快到达目标获得更大回报。

### 8.3 评价指标与重复实验

论文使用每个 episode 的**归一化总回报**评估学习效果。图中：

- 横轴为训练 episode；
- 纵轴为归一化 total return；
- 竖直虚线表示动作集合发生变化的时间；
- 阴影区域表示 5 个不同随机种子的标准差。

因此，论文同时考察平均性能、动作集合变化后的恢复速度和多随机种子稳定性，而不只比较最终最高分。

## 9. 对比方法

论文比较五种方法：

### Baseline (1)：重初始化的 Cal-QL + SAC 数据

- 基于 Nakamoto 等人的 Cal-QL 思路；
- 每次动作集合变化后重新初始化模型；
- 用 SAC 运行收集离线数据；
- 每次变化前重新离线训练，再进入在线改进。

### Baseline (2)：重初始化的 CQL + 专家数据

- 每次动作集合变化后重新初始化；
- 使用高质量专家数据；
- 使用 CQL 进行离线训练；
- 代表“数据质量较高但每次都重新开始”的方案。

### Baseline (3)：原始 LAICA

- 能在动作集合变化时继续适应；
- 不依赖全过程专家数据；
- 训练数据完全在线收集；
- 是论文重点要改进的持续 RL 基线。

### Baseline (4)：不重初始化的 Cal-QL 风格方法

- 使用离线到在线训练思想；
- 动作集合变化后不初始化模型；
- 但没有按 LAICA 的方式调整可用动作表示；
- 用来验证“普通 offline-to-online 方法”在动态动作集合下的局限。

### Cal-LAICA：本文方法

- 与 LAICA 类似保留持续动作表示能力；
- 仅在训练开始时使用一次专家数据；
- 约 5,000 个 episode 的 CQL 离线预训练；
- 后续在线适应不断加入的新动作；
- 使用 OORB 和 Q 值校准正则项。

## 10. 实验结果与解释

### 10.1 总体性能

图 5 的总体结论是：Cal-LAICA 在四类任务上都取得了更高的归一化回报，并且动作集合切换后下降更小、恢复更快。

具体观察包括：

- 相比 Baseline (1)，Cal-LAICA 不需要每次动作变化都重新初始化，保留旧知识的同时能适应新动作；
- 相比 Baseline (2)，Cal-LAICA 的数据采集成本显著更低，因为它不需要每个阶段重新准备专家数据；
- 相比原始 LAICA，Cal-LAICA 在动作集合连续增加时更加稳定，避免了 Q 值低估导致的随机策略更新；
- 相比 Baseline (4)，Cal-LAICA 保留了持续动作表示的优势，同时解决普通 offline-to-online 方法不能自然处理动作集合改变的问题。

论文还指出，动作集合越大、变化次数越多，可靠高质量经验越难获得；这会让未经校准的 Q 值估计更加困难。因此，Cal-LAICA 的优势不仅是最终分数更高，也体现在连续适应过程中的恢复速度和稳定性。

### 10.2 Q 值结果分析

图 6 对 Four Rooms 进行了 LAICA 与 Cal-LAICA 的平均 Q 值对比：

- LAICA 在第一次动作集合变化后平均 Q 值下降，但经过约 1,000 个 episode 可以恢复；
- 第二次、第三次变化后，LAICA 的平均 Q 值难以收敛，旧经验几乎被遗忘；
- Cal-LAICA 经过第一次和第二次变化后，平均 Q 值下降幅度更小，并分别在大约 200 和 400 个 episode 后停止继续下降；
- 价值曲线更平滑，说明校准正则项限制了低估误差向策略更新传播。

这个结果支持论文的因果判断：性能下降并非单纯因为动作多了，而是因为动作映射变化后，旧 Q 值和新表示空间不再完全对应，低估使策略主动放弃原本应该探索的表示区域。

### 10.3 消融实验

论文分别移除两个组件：

1. 移除价值校准，但保留 OORB，记作 `LAICA + OORB`；
2. 移除 OORB，但保留校准机制。

结果显示：

- `LAICA + OORB` 比原始 LAICA 更好，说明保留旧经验确实提高了样本效率；
- 但它仍会在动作集合变化后出现明显遗忘，说明 OORB 不能单独解决价值低估；
- 完整 Cal-LAICA 在四个任务上最稳定，说明价值校准是性能提升的关键组件；
- 移除 OORB 后，除了 Four Rooms 外，其他任务通常不如完整方法，说明历史经验对持续适应同样重要；
- 论文指出，如果参考策略所依赖的旧行为样本被丢弃，校准组件的有效性也会下降，因为它失去了可靠的参考价值。

消融结论可以概括为：

> OORB 解决“经验不够、样本浪费”的问题；价值校准解决“Q 值低估导致错误更新”的问题。两者互补，缺一都会降低持续泛化能力。

## 11. 相关工作脉络

论文把自身工作放在三个方向的交叉点：

### 11.1 Offline-to-Online RL

在线 RL 从零开始通常需要大量交互。离线到在线方法先利用已有数据训练，再用在线数据微调，能减少早期低质量探索。但它们面临分布偏移：在线策略会访问离线数据未覆盖的状态-动作对。

论文借用了这些方法中的：

- 离线预训练；
- 离线/在线混合回放；
- 对 Q 值进行保守校准；
- 让当前策略不要因估计误差而低于参考策略。

### 11.2 未见动作空间与潜在动作表示

另一类工作学习动作的潜在表示，把语义相近的动作聚到一个连续空间中，再从潜在表示映射回真实动作。这样可以减少大规模动作集合带来的直接输出负担。

但是，如果新动作持续加入，固定的映射和旧价值估计可能失效；如果只用一次性动作表示，又难以持续优化。LAICA 通过拆分动作映射和表示策略解决了持续更新问题，Cal-LAICA 则进一步处理价值低估。

### 11.3 Lifelong RL 与泛化

论文特别强调，RL 中的泛化不同于监督学习中的“在未见样本上预测正确”。一个真正泛化的 RL 智能体应当能够从环境中不同的可控状态出发完成目标，而不是记住少量轨迹。

对本文来说，泛化表现为：动作集合持续改变时，策略能够快速利用旧知识并适应新动作，而不是每次变化后重新从随机策略开始。

## 12. 论文的优点

1. **问题诊断具体**：没有停留在“动态动作空间很难”的层面，而是通过 Q 值曲线和回报曲线把失效原因定位到适应初期的价值低估。
2. **方法结构清晰**：校准正则项和 OORB 分别对应价值准确性与样本效率，组件职责明确。
3. **持续学习设定合理**：动作集合分阶段开放，且同时增加新目标，能够检验模型面对结构变化时的稳定性。
4. **实验比较覆盖充分**：包含从头重训、专家离线数据、原始 LAICA 和普通 offline-to-online 方案。
5. **报告了多次变化后的表现**：不是只测一次域变化，因而能体现遗忘累积问题。
6. **理论与实验相互对应**：理论中的校准 Bellman 误差转移系数对应实验中价值估计传播和恢复速度的分析。

## 13. 局限与阅读时需要保留的判断

### 13.1 目前只处理离散动作

论文在结论中明确承认，Cal-LAICA 当前只能处理离散动作空间，未来工作才考虑连续动作。这一点与连续控制任务（例如连续力度、角度、速度）存在直接差异。

### 13.2 实验规模和细节仍有限

正文主要给出曲线和定性比较，未在主文中列出每个任务的完整数值表、最终均值、置信区间数值或所有训练超参数。图中使用五个随机种子，但读者难以仅凭正文复现实验的全部细节。

### 13.3 动作数量需要正确读取上标

完整动作空间为 \(2^8=256\)，不是 28。它与五阶段分组的 51、51、51、51、52 完全一致。原总结关于“排版矛盾”的判断来自读取上标时的错误，不能当作论文的缺陷。

### 13.4 依赖参考策略与历史数据

价值校准需要参考策略价值。如果历史行为数据被完全丢弃，校准效果会下降。也就是说，方法并不是无条件地解决灾难性遗忘，而是依赖：

- 足够可靠的初始离线数据；
- 保留旧经验的回放池；
- 合理的 offline/online 采样比例 \(p\)。

### 13.5 校准可能带来保守偏差

论文强调的是防止低估，但从方法性质看，给 Q 值设置参考下界可能使估计更保守或抑制部分有益的快速下降。参考策略质量不高时，校准下界也可能限制策略改进。这一点需要在不同任务中单独验证。

### 13.6 与一般环境参数泛化不是同一个问题

本文研究的是“可执行动作的集合变了”，而不是重力、速度、地图纹理、奖励尺度等环境参数变化。因此，不能直接把 Cal-LAICA 的结果等同于所有形式的 domain generalization。

## 14. 对我们当前 WemiEnv 项目的启示

### 14.1 与当前 Flappy Bird 的关系

当前 Flappy Bird 环境是固定的二动作离散空间：

- `0`：不拍翅；
- `1`：拍翅。

它更接近固定动作空间的 PPO 训练，而不是本文的动态动作集合。若要直接复现本文思想，需要设计“动作集合逐阶段扩展”的游戏接口，例如先只允许一种动作，后续开放新的动作强度、动作时长或技能动作。

### 14.2 连续动作任务不能直接套用

当前 BottleJump 使用连续动作 \([-1,1]\)，内部映射为按压时长。论文明确只支持离散动作，因此不能直接把 Cal-LAICA 原样用于 BottleJump。若要迁移，需要重新设计：

- 连续动作的潜在表示和映射函数；
- 连续动作 Q 值校准；
- 连续动作的回放数据分布处理；
- 新动作“加入”的定义，例如新增可用力度区间、离散化粒度或技能原语。

### 14.3 可以先借鉴的工程结构

即使不立即实现 Cal-LAICA，本文仍给出可用于泛化实验的工程原则：

1. 保存所有阶段的经验，不要在环境变化时直接清空 replay buffer；
2. 把训练环境参数和测试环境参数明确分离；
3. 在每次环境/动作变化前后记录回报、Q 值、策略熵和恢复所需步数；
4. 用多随机种子报告均值和标准差；
5. 把“变化前性能”“变化后最低性能”“恢复到变化前 90% 所需步数”作为核心指标；
6. 对新动作出现后的早期价值估计做单独监控，防止策略因为 Q 值低估而停止探索。

### 14.4 对 FanHua 泛化实验的建议

如果后续以 Flappy Bird 为起点，可以先做一个简化版持续泛化实验：

- **阶段 1**：只使用默认管道生成规则，训练 PPO 基线；
- **阶段 2**：改变管道间隙或初始位置，测试固定策略的性能下降；
- **阶段 3**：增加新的离散动作，例如不同幅度的拍翅动作，模拟动作集合扩展；
- **阶段 4**：比较重训、继续训练、保留旧经验和校准价值估计四种方案；
- **评估**：记录平均回报、死亡步数、恢复步数、五个随机种子的均值和标准差。

这样能把论文中的“动作集合泛化”和我们原本计划的“环境参数泛化”区分开，同时为后续实现 PyTorch 版本的 Cal-LAICA 或其简化变体提供清晰基线。

## 15. 论文方法的逻辑链条

整篇论文可以压缩成下面这条因果链：

```text
动作集合增加
    ↓
潜在表示到真实动作的映射发生变化
    ↓
旧 Q 值不再完全对应新的动作语义
    ↓
适应初期数据不足，部分动作表示的 Q 值被低估
    ↓
策略降低这些动作表示的选择概率
    ↓
更难收集纠正低估所需的数据
    ↓
性能先崩溃，随后慢慢恢复，甚至多次变化后无法恢复

Cal-LAICA 的处理：
    Q 值校准提供参考价值下界
    + OORB 保留旧阶段经验并混合当前经验
    + 初始 CQL 离线预训练提供可靠起点
    ↓
降低低估和遗忘，提升新动作适应速度与样本效率
```

## 16. 最终结论

论文的核心结论不是“增加网络规模就能泛化到新动作”，而是：

> 在动态动作空间中，持续强化学习的关键瓶颈是动作映射变化后价值函数的错误校准。新动作出现时，低估会让策略主动放弃重要的动作表示区域，形成数据不足和性能下降的反馈回路。通过参考策略价值下界进行校准，并保存跨阶段经验，能够显著改善持续适应。

Cal-LAICA 的价值在于把三个思路结合起来：

- LAICA 的潜在动作表示与持续适应能力；
- 离线到在线 RL 的初始预训练与价值校准；
- 混合回放缓解历史数据浪费和当前数据不足。

但它的适用边界也很明确：实验主要针对离散动作集合的逐步扩展，连续动作、复杂视觉状态和一般环境参数变化仍需额外方法。对我们的 WemiEnv 研究而言，最值得迁移的不是直接复制算法，而是它的实验设计思想：**把环境变化显式分阶段，保留跨阶段数据，跟踪变化前后价值估计和恢复速度，并用多随机种子报告稳定性。**

## 17. 术语速查

| 术语 | 含义 |
|---|---|
| Lifelong RL | 持续/终身强化学习，智能体在多个连续变化的任务或环境阶段中持续学习 |
| Changing Action Set | 可用动作集合随训练过程增加或变化 |
| LAICA | 将真实动作映射到潜在动作表示空间，并在潜在空间学习策略的持续 RL 方法 |
| Cal-LAICA | 本文提出的校准版 LAICA |
| Action Representation Policy \(\beta\) | 根据状态选择潜在动作表示的策略 |
| Action Mapping \(\phi\) | 将潜在动作表示映射到真实动作 |
| Inverse Dynamics \(\psi\) | 根据状态变化和反馈帮助推断动作表示映射的函数 |
| Q-value Underestimation | 动作价值被估计得过低，可能导致策略停止探索该动作 |
| OORB | Offline-Online Replay Buffer，混合保存旧阶段和当前阶段经验的回放机制 |
| Cal-QL | 用参考策略价值校准 Q 值的离线到在线 RL 方法 |
| Bellman Error Transfer Coefficient | 衡量 Bellman 误差如何在价值迭代中传播的系数 |
| Regret | 最优策略与实际策略之间的累计价值差 |
