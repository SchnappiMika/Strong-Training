一、强化学习到底在做什么

可以把模型想成正在练游戏的玩家：不断尝试，观察结果，再调整自己的习惯。我们还使用了教师行为辅助训练，所以这里同时包含“从奖励学习”和“参考已有行为”的部分。

一个时间步的闭环：观测 → 动作 → 游戏反馈 → 下一次决策

先用一小段 Flappy Bird 理解“学习”

  1. 看情况：小鸟快碰到下方管道，程序收到小鸟和管道的位置数字。这些数字是观测。
  2. 做决定：网络根据当前参数输出一个动作，映射后是 1，也就是拍翅。程序把 1 发给游戏。
  3. 看后果：游戏执行动作，返回新位置、奖励和是否死亡。只有这一刻才能知道这次动作实际发生了什么。
  4. 记经验：把“刚才什么情况、做了什么、得到什么、后来怎样”保存下来。经验回放就是以后反复抽这些记录学习。
  5. 调参数：评分网络学习动作的未来价值；决策网络根据评分和行为指导调整参数，让以后类似情况更倾向于合适动作。

拍翅没有天然的“永远正确”标签。小鸟太低时拍翅可能有用，太高时拍翅可能撞上方管道，所以网络必须把情况和动作放在一起学习。一次存活也不能证明策略学会了，需要连续多步、多局检查。

1.1 MDP：把游戏写成五个东西

论文使用马尔可夫决策过程（MDP）描述环境：

M = (S, A, P, R, γ)

S：状态空间

决策所需的环境情况。例如小鸟位置、管道和速度。模型实际收到的是其中一部分，叫观测；本次收到结构化数字，没有读整张截图。

A：动作空间

模型能按什么按钮。本次两款游戏都只接受动作 0 或 1，但两个数字在不同游戏里的含义不同。

P：转移规律

游戏在执行动作后怎样变化。小鸟会下落或上升，树枝会向上移动。

R：奖励

动作带来的即时反馈。活着、过管道、砍树会贡献不同的奖励。

γ：折扣因子

未来奖励要不要打折。本次是 0.99，意思是当前奖励和稍后奖励都重要。

额外信息：回合结束

done 是接口反馈，不是 MDP 五元组的第六个字母。客户端说游戏自然结束时是 terminated；人为达到步数上限时是 truncated。

1.2 策略、参数和训练

策略（policy）就是“在这种状态下怎么选动作”的规则。神经网络里有很多数字，例如权重和偏置，这些数字统称参数 θ。训练时，模型根据一批历史数据计算损失，然后用梯度下降改变 θ。

观测 s游戏传来的数字
→
网络参数 θ当前的行为规律
→
动作偏好0 或 1 的选择
→
环境奖励告诉模型好不好
训练时参数会改变：模型根据数据算出损失，再调整权重和偏置。最终评估只读取参数，不做反向传播和优化器更新。

1.3 一步、一局、一次更新为什么不一样

词大白话本次例子
step / 交互步发送一次动作，收回一次反馈主线做了 80000 步，不是 80000 局
episode / 回合从 reset 开始，到自然结束或人为截断的一段游戏最终每款游戏测 20 局
update / 更新抽取一批数据，计算损失，执行优化器同一条经验可能被反复抽到，更新次数不必等于交互步数
batch / 小批量一次更新看的数据数量本次 batch_size=64，表示一次用 64 条经验

1.4 奖励和回报：一个是眼前，一个是一段未来

奖励 r 是一步反馈。回报 G 是多步奖励相加；训练常给更远的奖励打折。比如后面三步奖励依次是 1、2、3，折扣因子 γ=0.9，那么现在看它们的价值是 1+0.9×2+0.9²×3=5.23。

互动：改变你重视未来的程度

G = 1 + 0.90 × 2 + 0.90² × 3 = 5.23

γ 越接近 1，越看重远处收益。这里固定三步奖励演示；本次训练 γ=0.99。最终评估报告的 learning_return 是单局处理后奖励的直接和，没有再按 γ 打折。

1.5 Q 值为什么重要

Q(s,a) 可以读作：“在状态 s 做动作 a，考虑之后还能得到多少总回报”。如果模型错误地认为某个动作价值很低，它就会少选这个动作，因而更难收集纠正它的数据。这就是论文重点讨论的价值低估。

目标回报 ≈ 当前奖励 r + γ × 下一状态的最好价值

这里先把策略当成“下一步选自己认为好的动作”。本次 SAC 的精确目标还包含策略采样、终止标记、熵和双 critic，后面的算法节会逐项展开。

Q(s,a)：先指定第一步

“现在处于 s，我先做 a，以后按策略继续玩，大概能拿多少折扣回报？”例如眼前这步拍翅和不拍翅分别值得多少。

V(s)：按策略平均起来

“现在处于 s，按我的策略正常玩，大概能拿多少？”它把不同动作的 Q 按选择概率加权，不额外指定第一步。

1.6 参数、矩阵和梯度：你说的“调矩阵”在哪里

向量是一排数字，矩阵是很多排数字。比如 x=[小鸟高度, 管道下沿, 上方管道高度] 是一个向量。网络的一层会算 h=ReLU(Wx+b)：矩阵 W 把输入组合成新特征，b 是偏置，ReLU 把负数变成 0。把几层接起来，就得到能表达更复杂规则的神经网络。

本次网络输入是 12 个状态数加 2 个任务标签位。共享 backbone 的 Linear 层依次把维度从 14 变到 64、64、64；随后两个输出头分别产生 2 维均值和 2 维标准差信息。它们是同一个 actor 的输出头，不是按游戏分别建两个 actor。

训练需要一个损失 L 来衡量错误。梯度告诉我们“把某个参数稍微调大，损失会增加还是减少”。最基础的更新写成 w ← w − η×梯度。η 叫学习率，控制每次走多大一步。本次使用 Adam 优化器，它还维护历史梯度统计，因此 checkpoint 必须保存优化器状态。

互动：亲手调一个参数

教学模型只有一个参数 w。希望它对输入 x=1 预测出 2。损失 L=(w−2)²，梯度是 2(w−2)，学习率固定为 0.1。

w=0.000，预测=0.000，损失=4.000

真实模型同时调整很多权重，用的是多种损失和 Adam。这里让你看到“参数被训练改变”确实就是数字在变化。

反向传播、loss、optimizer 之间是什么关系？

前向计算得到预测；loss 把预测和目标变成一个误差数字；反向传播按链式法则求每个参数的梯度；optimizer 根据梯度更新参数。loss.backward() 算梯度，optimizer.step() 改参数。只看游戏画面不会自动改权重。

观测等于完整状态吗？马尔可夫是什么意思？

马尔可夫条件大致是：知道当前完整状态和动作，预测下一步不再需要更久的历史。但实际观测可能少了速度或计时信息。本次 Flappy Bird 只有三个坐标量，不能直接保证完整马尔可夫性；模型能通过测试，也不等于证明当前观测已经包含全部动力学信息。若以后研究更复杂变化，可能需要增加速度、帧堆叠或循环网络。

二、什么叫“一个共享模型”

最终交付的是一份共享模型：一个 actor、双 Q critic 和一组动作表示组件共同服务两款游戏。切换游戏时，保留模型参数，改变的是任务标签和交互环境。

为什么需要任务标签

两个游戏都把动作写成 0 和 1，但 0 在 Flappy Bird 是“不拍翅”，在 Timberman 是一侧砍树。任务标签像一张便签，告诉网络“这些数字属于哪款游戏”。

参数到底放在哪里

最终文件是 主线目录中的 checkpoints/latest.pt。它保存权重、优化器状态、熵温度、动作原型、经验回放、阶段和随机数状态，能恢复训练。.pt 与 .ckpt 都只是常用后缀；你同学说的 .checkout 要看实际保存代码，后缀本身不决定算法。

2.1 两位 critic 为什么仍然叫一个模型

actor 是做决定的人，两个 critic 是训练时从两路估计动作价值的评分器，它们都服务两款游戏。一个完整强化学习模型可以包含多个网络组件；“一份模型”指一套共同学习和保存的 agent，不要求内部只有一个矩阵。部署时动作来自同一个 actor 和任务对应的原型，critic 不作为两款游戏各自的执行者。

2.2 任务标签如何进入矩阵

任务标签采用 one-hot：Flappy Bird 是 [1,0]，Timberman 是 [0,1]。把它接到 12 维状态后，网络看到 14 维输入。例如 [0.4,0.6,0.2,0,…,0,1,0] 表示 Flappy Bird；标签换成 [0,1] 时，模型知道前面的数值要按 Timberman 编码解释。

本次“泛化”的准确位置：它是两个已知任务上的任务条件共享策略与持续能力保留。任务标签由训练器提供，没有让模型自动识别游戏，也没有让它看到第三款游戏就立即学会。论文里的新动作适应、已知双任务共享、未见环境零样本泛化，是相关但不同的问题。

从游戏数字到网络输入：亲手展开一次编码

以下坐标是教学假设值，编码规则来自本次代码。假设 Flappy Bird 返回三个位置数字 [240,360,120]。程序除以 600，得到 [0.4,0.6,0.2]。再补九个 0，形成 12 维状态：

s = [0.4, 0.6, 0.2, 0, 0, 0, 0, 0, 0, 0, 0, 0]

最后接上 Flappy 的任务标签 [1,0]，形成 actor 的 14 维输入。归一化就是把数值调整到较容易学习的尺度，240÷600=0.4 没有改变位置含义；补零是为了让两款游戏输入长度相同，不代表九个缺失观测被测成了零；任务标签让网络知道这份输入该按哪款游戏解释。

Timberman 原始观测是 11 组“方向、横坐标、纵坐标”，再加玩家侧别，共 34 项。本次取出 11 个方向和 1 个玩家侧别：没有树枝记 0，两侧分别记 −1 和 1。actor 再聚焦最近两段树枝和玩家侧别，远处方向置零；critic 仍保留 12 维完整编码。聚焦是减少决策输入干扰的工程处理，不是额外代替网络选动作。

奖励也要先转换，不能直接把分数当一步奖励

假设 Timberman 分数依次为 10、11、11、12。各步增量是 1、0、1。如果每次把累计分数 11、11、12 都当新奖励，就会重复计算前面已经取得的成绩。本次奖励是“分数增量−自然终止标记”，正常砍中一次为 +1，换边未得分为 0，死亡会额外减 1。

Flappy Bird 的客户端奖励除以 100 后用于学习。例如原始奖励 80 会变成 0.8。最终报告的学习回报是这些处理后奖励的直接和，不能读成“过了 2267 根管道”。不同游戏分别统计，避免把两种计分方式混在一起。

3.2 WemiEnv 论文：环境、框架与算法各自负责什么

WemiEnv 论文的贡献是把微信小游戏接到 RL 程序。它包含 JavaScript 客户端、Python WebSocket 服务端和统一接口；reset 是重开游戏，step 是发一个动作并收回反馈。论文提供六类示例：Space Fighter、Flip、2048、Flappy Bird、Timberman 和 Snake，并用 VPG、PPO、DDPG、TD3 等算法展示环境能用于训练。

层次例子本次作用
环境 / 接口WemiEnv；Gymnasium 是另一种环境接口生态游戏逻辑和观测反馈继续来自原 WemiEnv，FanHua 适配代码不导入 Gymnasium

3.3 为什么速度也是研究变量

WemiEnv 的游戏按真实时间运行。Python 正在算网络时，小鸟可能还在落、Timberman 的时间条可能还在减。因此“一步游戏反馈”不是固定一帧，延迟、训练计算和保存文件都可能影响结果。WemiEnv 论文的延迟实验在 Space Fighter 和 Flappy Bird 上人为加入 10、20、50、100 毫秒延迟，观察到性能受影响；这些是论文实验设置，不能当成本次测出来的延迟。

协议里的数字例子：Timberman 连续反馈累计分数 10、11、12，训练奖励应是 1、1，不能再把 11、12 都算成新增奖励。Flappy Bird 的缩放只改变奖励数值尺度，不把它变成真实过管得分。

四、论文和算法：先懂直觉，再看名字

4.1 论文到底研究什么

论文题目是“面向变化动作集合的校准持续强化学习”。它研究的是：智能体已经会一批离散动作，训练途中又逐步开放新动作，怎样复用旧知识并快速适应。这里的“泛化”主要指动作集合变化后的持续适应，不等同于所有形式的环境参数泛化。

论文的因果链：动作映射变化可能让价值函数低估，低估又会阻止策略探索。

论文的困难：为什么新按钮出现，旧经验也可能变难用

设想游戏最初只有“慢走、快走”两个按钮，网络先输出坐标 e，再按映射选按钮。以后增加“冲刺”，动作坐标的划分发生变化，原来某个 e 代表快走，现在可能代表冲刺。评分器如果仍按旧经验理解 e，就可能给新行为错误的分数。

低估会形成循环：新动作实际很好 → 评分器却觉得很差 → 策略很少选择它 → 收不到足够的新反馈 → 错误评价难以纠正。论文用参考价值参与校准，并用历史与当前经验共同学习，尝试减少这种适应障碍。

本次两款游戏都固定为两个动作，没有逐阶段开放新按钮。我们借鉴的是表示、价值稳定和经验复用方法，再增加任务标签适配跨游戏。由此得到的是已知双任务的共享策略；不能直接套用论文的动作扩展实验结论。

4.2 潜在动作表示：把“按钮”变成坐标

潜在空间就是网络内部的一块数字坐标空间，本身不是游戏画面。LAICA 先让策略在这里选位置 e，再把它映射成真实动作 a。可以理解为“先在地图选点，再看这个点离哪个按钮更近”。

eₜ ~ β(· | sₜ)，　aₜ = φ(eₜ)

β：表示策略

根据状态在潜在空间里选一个位置。当前代码里的 shared actor 就承担了这部分。

φ：动作映射

把潜在位置映射到真实动作。本次用每个任务的两个动作原型做最近邻选择。

ψ：逆动力学

根据状态变化和动作反馈，帮助学习“哪个潜在位置更像这个动作”。

为什么有用

策略的共享部分可以复用，游戏动作的差异放到任务条件和动作原型中处理。

互动：二维坐标如何变成动作

教学原型固定为 p₀=(−0.6,−0.6)、p₁=(0.6,0.6)。滑块代表 actor 输出的 e，按平方距离选更近的原型。

这两个坐标是教学值，不是最终 checkpoint 的原型值。真实原型先学习，再冻结；历史经验中的动作表示要保持一致，不能随意换坐标。

先认识 SAC：做决定时兼顾价值和探索

SAC（Soft Actor-Critic）是一类 actor-critic 算法。actor 提出动作，critic 评价动作。探索是尝试可能还没把握的动作；利用是优先执行当前觉得好的动作。完全不探索，会一直重复早期的错误偏好；一直随机，又难以稳定游戏。

熵 H描述策略有多分散。例如两个动作概率是 0.5/0.5，比 0.99/0.01 更不确定。本次 actor 用高斯分布在连续潜在空间采样，tanh 把向量压到 (−1,1)。熵温度 α 控制多重视这种探索倾向。训练时随机采样；评估时用潜在均值映射动作，所以评估策略是确定性的。

Actor 最小化：平均 [α log π(e|s) − min(Q₁(s,e), Q₂(s,e))] + 行为约束

读这式子时先看方向：降低损失会鼓励更高价值，并保留一定探索。log π 是动作表示的对数概率，α 是可学习的权重。“loss 变成负数”不一定出错；它也不等于游戏成绩变差。

双 Q 和目标网络：评分器也要稳定

双 Q 是两个独立评分器，训练和 actor 目标里取较小值，减少一条评分路径偶尔高估造成的乐观偏差。目标网络是 critic 的缓慢副本，用来生成下一步学习目标，避免双方一起剧烈变化。本次 τ=0.005，软更新写成 target ← 0.995×旧 target + 0.005×当前 critic。例如旧值 8、当前值 10，更新后是 8.01。

4.3 CQL、Cal-QL 和 Cal-LAICA 的区别

CQL：保守 Q 学习

离线数据不覆盖所有动作时，CQL 用保守项压低不可靠的动作价值，减少模型“自信地瞎猜”。

Cal-QL：价值校准

除了保守，还用参考策略价值作为下界，避免新策略由于估计误差被评价得过低。

Cal-LAICA

把价值校准放进潜在动作表示空间，并配合旧经验和当前经验的混合回放，服务动作集合持续变化。

“保守”和“防止低估”同时出现，是因为要控制两种错误：数据外动作可能被盲目高估，有用动作又可能被保守项压得过低。校准在保守目标里引入参考价值；它依赖参考数据质量，不能把差教师自动变成好教师。

论文校准正则示意：R = E[max(Q(s,e), Vμ(s))] − E数据动作[Q(s,e)]

μ 是参考行为策略；E 表示对多条数据取平均。论文希望减少低估，本次代码通过损失中的 max 分支实现。它没有在推理时把所有 Q 硬改成某个下界，也没有保证每条 Q 在每一步都大于参考值。最终动作依然由 actor 和原型映射产生。

互动：下界究竟替换哪里

max 的结果进入正则项，不直接改写 critic 的输出。Q 低于下界时，这个候选分支对原 Q 的局部梯度为 0；Q 高于下界时才继续由 Q 分支传梯度。真实 CQL 还做 logsumexp、密度校正和数据 Q 相减，不能把这个小算式当完整训练器。

TD 与 MC：两个产生学习目标的方法

TD（时序差分）用“当前真实奖励 + 下一步估计值”构造目标。若 r=1、γ=0.99、下一步 Q=10，暂时忽略熵，那么目标是 10.9；现在预测 8，就用 (8−10.9)² 衡量误差。MC（蒙特卡洛回报）则把一整段实际奖励从后向前累计，例如 γ=0.9、奖励 [1,1,0]，从第一步看回报是 1.9。

自然终止和截断在训练中不一样：真死亡以后没有下一步，TD 目标不继续加未来值。3000 步人为停下时游戏本来还能继续，TD 保留下一状态估计，这叫 bootstrap（用估计补上没观测到的后续）。本次只让真正终止的完整轨迹提供 valid_bound；截断和断线片段不被假装成可靠 MC 下界。

4.4 OORB：为什么保存旧经验

OORB 是 Offline-Online Replay Buffer。历史池像长期记忆，在线池像刚发生的事情。切换任务或阶段时，把在线池转入历史池，再清空当前池；训练时按比例混合采样。本次配置历史经验采样概率为 0.25。

4.6 教师、预训练、微调分别指什么

教师是已经保存的行为模型，对一批状态给出动作建议。它与课题组老师这个称呼不同。预训练是先用已有离线数据建立起点；微调是保留起点参数，在新的数据和目标上继续更新。本次使用旧 PPO 的 Flappy Bird 行为和已验证的 Timberman 行为作为训练指导，最终只部署学生共享 actor。

行为约束由交叉熵与原型距离的均方误差组成：交叉熵鼓励选到教师建议的动作，均方误差把潜在均值拉近对应原型。它的权重 5.0 影响更新方向。强指导可能提高稳定性，也可能限制学生超越教师，当前没有无指导消融来确认各组件独立贡献。

交叉熵、MSE、KL、logsumexp 怎样理解？

交叉熵 CE：给正确动作的概率太小会受更大惩罚，单个目标的核心是 −log(正确动作概率)。目标概率从 0.1 增到 0.9，惩罚就减小。MSE：差值平方后平均，例如预测 2、目标 3，平方误差为 1；预测 0 则为 9。

KL 散度：度量两个概率分布的偏离程度，原型预热里用它约束逆动力学的高斯表示，避免分布随意漂走，它不是一般意义的对称距离。logsumexp：对候选值先指数、相加、取对数，像平滑版的最大值；大候选贡献更大。CQL 候选还做概率密度修正，因此不能把它当作简单平均。

论文参考价值是策略期望值；本次用完整轨迹的 MC 回报作估计。单条回报存在随机性，不是知道真实期望价值的“标准答案”。正则项是否有效，需要实测和对照。

遗憾界、Bellman 误差、函数类这些理论词是什么意思？

regret（遗憾）是每一轮“最优策略价值减当前策略价值”再累计。Bellman 误差衡量 Q 对“当前奖励加后续价值”是否自洽；误差转移系数描述不同策略访问数据的分布下，误差如何传播。函数类 F 是允许使用哪些 Q 函数的集合，rank 描述相关结构复杂度。论文定理的界包含参考策略质量、数据覆盖和函数结构等条件；读成“合理条件下限制适应损失”即可，不能读成“任何神经网络跨游戏一定成功”。这份工作没有计算对应常数或验证定理假设。

这和推荐系统有什么联系？

可以把用户近期行为看成观测，把推荐哪个物品看成动作，把点击、购买或长期满意度看成奖励。新物品加入会让动作集合变化，因此潜在动作和持续适应思想有参考价值。但真实推荐还涉及曝光偏差、延迟反馈与评价方法。本次没有训练推荐系统，小游戏成绩不能当成推荐效果。

五、一次训练是怎样发生的

1. 读取观测

WemiEnv 从微信客户端收到 obs、reward、done。训练器检查类型、长度和数值范围，防止错误项目混入。

2. 选择动作

共享 actor 读取 12 维状态和任务标签，产生潜在动作；动作原型把它变成 0 或 1。

3. 保存这条经验，等边界时入池

state、action、reward、next_state、终止标记先进入当前回合的 pending 列表；回合结束、截断或阶段边界时计算回报并放入在线池。因此首段数据尚未入池时可能只有交互，没有 SAC 更新。

4. 更新 critic

双 Q critic 学习 TD 目标，同时加入 CQL 候选动作的保守项和校准项。

5. 更新 actor

actor 根据 critic 的价值和熵目标调整，并在配置启用时加入行为约束。

6. 软更新目标网络和保存

目标 critic 逐步靠近当前 critic，训练器定期保存 latest.pt，断线时可以从上一个安全点恢复。

完整数值例子：一条经验怎样推动参数变化

下面用教学假设值串起整个过程。为便于手算，先忽略 SAC 熵项、CQL 和其他样本，只演示一个 TD 平方误差；真实网络使用多条数据、多个损失和 Adam。

  1. 取得真实转移：当前状态 s 下选择拍翅，收到奖励 r=1、新状态 s′ 和“未死亡”。记录 (s,动作,1,s′,未终止)。经验是数据，尚不是参数。
  2. 组成学习批次：回合结束或阶段边界时，这些 pending 记录才入池；池中有足够数据后，从当前池和历史池抽 64 条组成 batch。
  3. 算学习目标：假设两个目标 critic 对下一步的估计为 10 和 12，先取较小值 10。γ=0.99，因此 y=1+0.99×10=10.9。y 是当前数据与下一步估计组成的目标，不是游戏直接返回的分数。
  4. 算当前误差：假设当前 critic 预测 Q=8，L=(8−10.9)²=8.41。这个误差告诉评分器当前预测偏低。
  5. 看参数怎样动：进一步把 Q 简化成单参数 w=8，则梯度为 2(w−10.9)=−5.8。教学学习率 0.1 下，w←8−0.1×(−5.8)=8.58。新误差 (8.58−10.9)²=5.3824，确实变小。
  6. 再更新决策网络：真实训练随后让 actor 倾向于 critic 评价较高的潜在动作，并兼顾探索和教师动作约束。critic 的 w 改好，不会自动等于 actor 改好，它们分别有优化步骤。

若本条经验是真的死亡，TD 不再补下一步价值，目标就是当前奖励。如果只是达到人为上限，游戏仍可继续，TD 会保留后续估计。完整自然终止轨迹还能给校准提供 MC 回报；截断片段在本次实现中不提供有效 MC 下界。

互动：逐步查看同一条经验

这是页面内的教学演示，只改变演示数字。模型文件和真实训练状态不会改变。

从简化例子走到真实 SAC 更新

y = r + γ(1−d) × [min(Q₁目标(s′,e′),Q₂目标(s′,e′)) − α log π(e′|s′)]

r 是这一步真实奖励；d 是自然终止标记，真死亡为 1；γ 是未来打折系数；e′ 是策略在下一状态采样的潜在动作；π 是这个动作的概率密度；α 是探索温度。方括号就是带探索项的下一步价值。这里的“目标”表示缓慢变化的 critic 副本，前文算 10.9 时暂时省略了熵项。

critic 用预测和 y 的误差学习，再加入保守/校准正则。actor 用 critic 的评分学习自己的输出；行为约束让输出与教师建议更接近。两者的参数方向都由反向传播和优化器计算，不是人工逐个把矩阵数字改成正确答案。

教师监督的一次小例子

假设教师建议动作 1，学生根据原型距离计算出的动作 1 概率只有 0.2，交叉熵惩罚是 −ln(0.2)≈1.609；如果学到概率 0.8，惩罚变为 −ln(0.8)≈0.223。ln 是自然对数，在此只要理解“给教师动作的概率越小，惩罚越大”。另一个 MSE 项把学生潜在均值拉近动作 1 原型。本次权重 5.0 调节这类监督对 actor 的影响，教师本身保持冻结。

为什么阶段结束后做 5 局短评估

每个 20000 步阶段结束后，训练器暂停更新，用当前参数做 5 局、每局最多 300 步的检查。它是当前阶段游戏的快速检查。它不会在每个阶段同时重测两款游戏，也不能单独证明旧任务完全没遗忘；最后的双游戏长评估才检查同一终点的两种能力。

短评估输出

从哪里继续，为什么 80000 不等于 73056

正式主线之前，共享起点已有 3000 次 SAC 更新和单独登记的监督修复。后续 3072 步冒烟又增加了 2052 次 SAC 更新，所以主线进入时计数为 5052；主线新增 68004 次，最终为 5052+68004=73056。监督修复、动作表示训练和 SAC 计数是分开的，这个计数不表示所有优化器累计调用总数。

主线 80000 步只统计该运行里的训练交互，起点数据、冒烟交互和评估交互不混进去。两个游戏各训练 40000 步，四阶段一直继续共享参数。正式前的单游戏基线是参照试验，不是最终交付，也没有把各自权重合并。

目录里多个 stage_XX.pt 是同一模型不同时间的历史快照，不表示部署时要轮流调用很多模型。最终部署只选择训练终点的 latest.pt。

随机初始化、seed 0/1 为什么存在？

随机初始化的是权重等初始参数。基线从各自随机起点训练，是为了检查独立训练结果是否稳定；seed 0 与 seed 1 不是同一个模型内部的两组参数。本次最终主线保留经过预训练和修复的共享起点，没有重新随机初始化；它只完成一条共享续训链。重复基线不能替代最终主线的多种子重复。

七、术语速查

Agent / 智能体

负责观察环境、选择动作、从反馈中学习的程序。在本次任务里，它是 PyTorch 训练器加共享模型。

Actor / Policy

根据状态决定动作的网络。训练时它和 critic 一起更新，评估时只用它做确定性动作。

Critic / Q 网络

评价状态和动作未来能得到多少回报。本次有两个 critic，取较小值来减少价值过高估计。

Replay Buffer

经验回放池，保存过去的 state、action、reward、next_state。训练从池里抽样，而不是只用最新一步。

梯度更新

损失对参数的方向信息。模型沿着能降低损失的方向修改参数，这就是一次 update。

Checkpoint

训练中保存的可恢复快照。.pt 是 PyTorch 常见后缀，不代表只有参数；本次还保存优化器、回放和进度。

Seed

随机数初始化种子。同一个模型只有一份权重时，seed 0、seed 1 通常指两次独立训练的随机起点，用来检查稳定性，不是同一模型的两份参数。

泛化

本次语境是让同一个共享策略处理两款已知游戏，并在任务切换后保持能力。它不自动等于对第三款未见游戏的零样本泛化。

论文中的 regret / 遗憾

可以理解为“理想最优策略和当前策略之间累计差了多少”。论文用理论界说明校准和历史经验有助于减少持续适应期间的损失。

Off-policy、Offline、Online 三个词

Online 是继续从环境收集新交互，Offline 是在已存数据上更新。Off-policy 是可以用其他或旧行为策略产生的数据来学习，SAC 属于这类；它并不等于 Offline。主线一边真实交互一边混合历史经验，仍是在线训练。

PPO 与 SAC 为什么都出现？

PPO 是先前 Flappy Bird 策略使用的算法，其更新围绕当前策略新采样的数据并限制策略变化。本次共享主线采用潜在 SAC/CQL 风格组件，PPO 仅作为教师来源之一。PyTorch 是计算框架，PPO 与 SAC 才是训练规则。

灾难性遗忘与分布偏移

灾难性遗忘是学新任务后旧能力大幅下降；分布偏移是现在遇到的状态和动作组合与以前数据不同。两者可能相关，不能从一次低分就判断原因。需要同 checkpoint 复测、原始日志和受控对照。

归一化、超参数与学习参数

把坐标除以 600 是输入缩放；把 Flappy 奖励除以 100 是奖励缩放；它们不等于论文曲线的归一化成绩。权重、偏置、动作原型和温度属于模型内部参数。学习率、batch_size、历史比例和行为权重属于人为设定的超参数，保存在 config.json。参数在训练中自动改变，超参数按实验设置控制。

均值、样本标准差、置信区间

均值是多局分数的平均。样本标准差描述单局围绕均值的散布，本次用 statistics.stdev，分母是 n−1。标准差不是“均值有多准确”的置信区间；20 局同一 checkpoint 也不是 20 次独立训练。这里没有计算统计显著性或泛化置信区间。
